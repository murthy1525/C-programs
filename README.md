# C Programs

This is a collection of small C programs. I wrote these to practice the basics of C programming, like loops, conditions, and switch statements.

## Programs in this repo

| File | What it does |
| --- | --- |
| `balance_checking.c` | Checks a bank balance and lets you deposit or withdraw money. |
| `department_lookup.c` | Takes a student ID and shows which department the student is in. |
| `marriage_eligibility_check.c` | Checks if a person's age meets the legal age for marriage. |
| `park_ticket_price.c` | Works out the ticket price for a park based on age or category. |
| `service_center_billing.c` | Calculates the bill for a service center based on the service type. |
| `student_grade.c` | Takes student marks and prints the grade. |
| `student_marksheet.c` | Prints a mark sheet for a student using subject marks. |
| `tea_stall_billing.c` | Calculates the total bill for items ordered at a tea stall. |
| `triangle_type.c` | Takes three sides and tells you what type of triangle it is. |

## How to run

1. Install a C compiler (for example, GCC).
2. Compile a file:
   ```bash
   gcc balance_checking.c -o balance_checking
   ```
3. Run it:
   ```bash
   ./balance_checking
   ```

## Why this repo exists

These are beginner-level practice programs, not a finished product. They show basic C skills: input/output, conditions, loops, and simple logic.
